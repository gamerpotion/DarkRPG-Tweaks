# Description

DarkRPG Tweaks provides essential bug fixes, compatibility patches, and stability improvements for the [DarkRPG Fabric Modpack](https://www.curseforge.com/minecraft/modpacks/darkrpg). It is a required mod for the latest releases of DarkRPG Fabric.

Originally developed to address compatibility issues introduced by updates to [Spell Engine](https://www.curseforge.com/minecraft/mc-mods/spell-engine), the mod has since expanded to include additional crash fixes, combat adjustments, equipment balancing, and quality-of-life improvements.

### What's Included?

#### **Compatibility & Crash Fixes**

✅ **Amethyst Core / Spell Power:** Fixes compatibility issues affecting spell-power integration.  
✅ **Origins / Apoli:** Prevents missing-layer crashes and protects against power synchronization errors when players disconnect.  
✅ **Cosmetica / Spell Engine:** Fixes compatibility issues between Cosmetica and Spell Engine.  
✅ **More RPG Library:** Prevents crashes related to PvP damage reflection.

#### **Combat & Equipment**

✅ **Soulslike Weaponry / Spell Engine:** Includes 24 spell-assignment overrides to improve weapon compatibility.  
✅ **TieredZ:** Includes 144 balanced equipment modifiers with corrected attribute values.  
✅ **TieredZ Reforging:** Adjusts reforging odds and ensures modifier registries remain consistent after datapack reloads.

#### **Quality of Life**

✅ **Traveler's Backpack / Trinkets:** Adds a backpack access button near the Inventory Profiles Next controls, avoiding inventory slot overlaps.  
✅ **Compact FPS Counter:** Adds a small, unobtrusive FPS counter in the bottom-right corner of the screen.

#### **Misc Info**

✅ Although developed specifically for DarkRPG Fabric, the compatibility fixes and improvements may also benefit other modpacks using the same mods.
